# Junseo's Minihompy ♡

싸이월드 감성의 반응형 팬사이트 시작 파일입니다.

## 실행 방법
- `index.html`을 브라우저에서 열면 미리보기를 볼 수 있습니다.
- 실제 공개하려면 GitHub Pages, Netlify, Vercel 등 정적 호스팅에 파일을 올리면 됩니다.

## 현재 구현된 것
- 하늘색/구름/레트로 미니홈피 스타일
- 반응형 메뉴 및 팝업 창
- Profile / FAQ 노션 원본 링크와 임베드 시도
- X 공식 계정 타임라인 임베드 시도 및 #준서 검색 링크
- Instagram 공식 계정 및 #준서 검색 링크

## 중요한 제한
- 노션 페이지는 외부 임베드를 차단하거나 공개 설정이 필요할 수 있습니다. 이 도구 환경에서 원문 콘텐츠를 확인하지 못했으므로, 노션의 문구와 사진을 복제했다고 주장하지 않습니다.
- X에서 전체 게시물이나 오래된 게시물까지 자동으로 검색/갱신하려면 X API 개발자 계정과 접근 권한이 필요합니다. 토큰은 브라우저 코드에 넣지 말고 서버 환경변수에 보관해야 합니다.
- Instagram의 API 기반 해시태그 검색은 Meta 개발자 앱, 적절한 Instagram professional account/permissions 및 토큰이 필요하며 공개 API의 제한을 따릅니다. 계정 피드 임베드도 모든 게시물을 그대로 표시하지는 않습니다.
- 이 ZIP은 사이트 소스이며 이미 인터넷에 배포된 주소가 아닙니다. 공개 배포와 API 인증은 별도 단계입니다.
- 준서의 실제 사진은 저작권/사용 허락이 있는 파일로 추가하세요. 현재 화면은 실제 인물 사진 대신 디자인용 자리표시자를 사용합니다.

## 사진 바꾸기
`index.html` 안의 `.avatar`와 `.hero-photo` 요소를 찾아, 사용 허락을 받은 이미지의 `<img src="images/파일명.jpg" alt="김준서">`로 바꾸고 `images` 폴더에 파일을 넣으면 됩니다.


## 사용자 제공 콘텐츠 반영
- `images/junseo-profile.png`: 사용자가 제공한 준서 프로필 사진
- Profile 메뉴: 사용자가 제공한 프로필 정보 표시
- FAQ 메뉴: 사용자가 제공한 6개 FAQ와 관련 링크 표시


## 디자인 개선
- Pretendard 우선 폰트 스택과 자간/행간 조정
- 사진을 `images/junseo-profile.png` 상대경로로 연결했습니다. ZIP 안에 이미지가 함께 포함되어 있어야 합니다.
- 사진이 보이지 않으면 ZIP 전체를 압축 해제한 뒤 `index.html`을 열어 주세요. HTML 파일만 따로 옮기면 상대경로 이미지가 표시되지 않습니다.

## 공개 방명록 연결하기 (Supabase)

현재 `index.html`에는 Supabase 공개 방명록 연결 코드가 준비되어 있습니다. 아래 설정 전에는 브라우저 로컬 저장 방식으로 동작합니다.

1. https://supabase.com 에서 계정을 만들고 **New project**로 프로젝트를 만듭니다.
2. 프로젝트의 **SQL Editor**에서 아래 SQL을 실행합니다.

```sql
create table if not exists public.guestbook (
  id bigint generated by default as identity primary key,
  nickname text not null check (char_length(nickname) between 1 and 24),
  message text not null check (char_length(message) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.guestbook enable row level security;

grant select, insert on public.guestbook to anon;
grant usage, select on sequence public.guestbook_id_seq to anon;

create policy "Anyone can read guestbook"
on public.guestbook for select to anon
using (true);

create policy "Anyone can add guestbook messages"
on public.guestbook for insert to anon
with check (
  char_length(nickname) between 1 and 24
  and char_length(message) between 1 and 500
);
```

3. Supabase 프로젝트의 **Connect** 또는 **Project Settings → API Keys**에서 프로젝트 URL과 publishable key(구형 프로젝트는 anon key)를 찾습니다. `service_role`/secret key는 절대 사용하거나 웹사이트에 넣지 마세요.
4. 프로젝트 URL과 공개용 키는 `index.html`에 이미 입력되어 있습니다. 다른 프로젝트를 사용한다면 해당 값을 바꿔 주세요.
5. 저장한 파일을 다시 사이트 호스팅에 배포합니다. 이제 방문자들이 같은 방명록을 읽고 남길 수 있습니다.

**안전 참고:** 공개 방명록은 누구나 글을 남길 수 있어 스팸이 생길 수 있습니다. SQL은 공개 읽기/추가만 허용하고 수정·삭제는 허용하지 않습니다. 사이트를 널리 공개하기 전에는 CAPTCHA/속도 제한과 신고·관리 방법도 고려하세요. 공개용 키는 브라우저에 있어도 되지만 `service_role` 또는 secret key는 절대 노출하면 안 됩니다.
